# 无名杀 · 大模型AI

让兼容 OpenAI Chat Completions 的大模型在无名杀中辅助 AI 决策的扩展。

## 功能概览

- 根据当前局势、技能、候选行动和历史记录辅助 AI 决策
- 支持聊天关联战局、行动计划、局内记忆和原版 AI 兜底
- 可配置 API 地址、模型、超时、重试和原版 AI 接管策略
- API Key 仅由游戏本地设置保存；本仓库不包含 API Key

## 安装与使用

完整安装步骤、首次 API 配置和安全注意事项请阅读：[用户使用说明](./用户使用说明.md)。

开发与维护说明请阅读：[AI 接手指南](./AI接手指南.md)。

## 发布内容与隐私

仓库仅包含扩展源码和公开默认配置。运行日志、AI 决策日志及本机导出的设置快照已由 `.gitignore` 排除；请勿把 API Key、整个游戏的用户数据目录或其他个人配置提交到仓库。

当前仓库未附带开源许可证；除适用法律另有规定外，保留所有权利。
